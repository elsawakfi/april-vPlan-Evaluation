# APRIL AI Hub x Analog Devices: Verification-Relevant Content Selection and vPlan Evaluation

This repository is part of the **APRIL AI Hub** (*AI for Productive Research & Innovation in eLectronics*) Summer Internship Programme and a research project funded by **Analog Devices**.

The project explores the use of Artificial Intelligence to analyse semiconductor specification documents, with a particular focus on:

- Extracting structured information from specifications
- Identifying and curating verification-relevant content
- Preparing high-quality datasets for downstream verification tasks
- Evaluating AI-assisted verification workflows

## Overview

The work is based on a range of industry-standard protocol specifications, including:

- AMBA APB
- AMBA AXI
- UART
- SPI
- I²C
- RISC-V

## Project Objectives

This repository focuses on two main tasks:

1. **Verification-Relevant Content Selection**
   - Identify requirements, protocol behaviours, timing rules, reset behaviour, and corner cases from specification documents.
   - Filter out descriptive information that is not useful for verification activities.
   - Produce curated datasets for downstream processing.

2. **Relevance Quality Evaluation**
   - Verify that extracted information is testable and verification relevant.
   - Detect missing requirements and duplicated information.
   - Assess the quality of the curated datasets.
